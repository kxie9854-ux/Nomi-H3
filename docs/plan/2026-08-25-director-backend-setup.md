# 导演首次打开：缺登录 / 缺生成后端时领到配置

日期：2026-08-25

## 为什么现在做

空项目说一句想法已经走通。还没配 AutoDL.art 或 Codex 生图时，导演要到 `nomi_list_models` 才停，用户不知道去「模型接入」。

## 范围

- 导演侧栏根据 catalog 派生静帧/视频是否可用。
- 缺任一后端时显示一条设置条，按钮打开既有模型设置（`nomi-open-model-catalog`）。
- 未登录 ChatGPT 仍用现有登录按钮，不另做第三套登录。

## 不动项

- 不改 H3 / imagegen 供应商。
- 不把 Nomi 目录里的 text 模型接到 Codex 导演。
- 不拦截发送；设置条是引导，不是硬门。
